# Changelog / 决策记录

> 给"考古"用的:**为什么这么写** + **改了什么**。每条都注明日期 / 改动 / 原因,后人查 git 之前先看这里。

## 文件

- [decisions.md](./decisions.md) — 重要决策(架构、命名、约束),影响后续设计。
- 待补充:`features.md`(按时间排的功能列表)、`regressions.md`(重大回归与修复)。

## 怎么追加

新决策请按下面的模板追加到 `decisions.md` 末尾,**不要覆盖历史条目**:

```md
## YYYY-MM-DD · 一句话标题

**背景**:为什么需要做这个决策。
**决定**:选了哪个方案。
**理由**:相比其他方案,为什么这个更好。
**代价**:这个方案有什么取舍。
**影响**:会影响哪些模块 / 后续工作。
```

PR 标题里加 `[decision]` 前缀,评审时关注。
